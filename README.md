# SnipKeep Legal

SnipKeep のプライバシーポリシーと利用規約を公開する静的サイトです。

- [プライバシーポリシー](https://kozuna-1216.github.io/SnipKeep-Legal/privacy/)

## 公開

`main` ブランチへの push または GitHub Actions の手動実行で GitHub Pages にデプロイします。ページは HTML/CSS のみで構成されています。

## ポリシー更新時の確認事項

本文は `kozuna-1216/SnipKeep` の `develop` ブランチで確認できた実装（端末上のスニペット保存、Apple iCloud/CloudKit 同期、StoreKit による買い切り Pro）をもとに作成しています。アプリの機能、データの取り扱い、価格、問い合わせ先に変更があった場合は、公開前に本文も見直してください。法令への適合性については、必要に応じて専門家に確認してください。
