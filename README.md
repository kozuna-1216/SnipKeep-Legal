## 公開

GitHub Pages を初めて使うときは、リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択してください。その後、`main` ブランチへの push または **Actions → Deploy static site to GitHub Pages → Run workflow** でデプロイできます。ページは HTML/CSS のみで構成されています。

## ポリシー更新時の確認事項

本文は `kozuna-1216/SnipKeep` の `develop` ブランチで確認できた実装（端末上のスニペット保存、Apple iCloud/CloudKit 同期、StoreKit による買い切り Pro）をもとに作成しています。アプリの機能、データの取り扱い、価格、問い合わせ先に変更があった場合は、日本語・英語双方の本文を公開前に見直してください。法令への適合性については、必要に応じて専門家に確認してください。
